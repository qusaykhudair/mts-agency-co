# MTS Agency + MTS Store

موقع **MTS Agency** مع **متجر اشتراكات رقمية** متكامل (ChatGPT، Claude، Canva، CapCut Pro، Gemini، Netflix…) يشمل:

- **صفحة رئيسية للوكالة والمتجر** على `/` تعرض بيانات المتجر الحية (المنتجات والعروض والأسعار وطرق الدفع) مع خدمات الوكالة وعملائها والضمان والأسئلة الشائعة.
- واجهة متجر احترافية (الرئيسية، الأقسام، المنصات، صفحة المنتج بالباقات والخصومات والعدّاد، البحث الفوري، الوضع الليلي، متوافقة مع الجوال).
- تسجيل دخول يدوي بالبريد وكلمة المرور **أو عبر Google**، مع **رقم واتساب إلزامي واختيار رمز الدولة** (يُطلب من مستخدمي Google في خطوة «إكمال البيانات»).
- إتمام الطلب بالتحويل: بنك فلسطين، جوال باي، بال باي (عبر iBURAQ إلى الآيبان)، فودافون كاش — تظهر تفاصيل الحساب والمبلغ بعملة كل طريقة، ثم يرفق المشتري اسمه ورقم الحساب المحوَّل منه وصورة الإيصال.
- **لوحة المشتري**: الطلبات ومراحلها، بيانات الاشتراك المسلَّمة (نسخ/إظهار)، الاشتراكات النشطة ومدة الانتهاء، الإشعارات، الملف الشخصي، طلب الانضمام كبائع.
- **لوحة البائع/المدير**: مراجعة الإيصالات، تأكيد أو رفض الدفع مع السبب، تسليم بيانات الاشتراك بقوالب جاهزة، مراسلة العميل عبر واتساب برسائل جاهزة، المنتجات والباقات، المنصات، الأقسام، طرق الدفع، أسعار الصرف، المستخدمون والصلاحيات، طلبات البائعين، التقييمات، الإعدادات.

## التشغيل على جهازك

المتطلبات: **Node.js 22.13 أو أحدث** (لا حاجة لقاعدة بيانات خارجية — يستخدم SQLite المدمجة في Node).

```bash
npm install
```

انسخ ملف الإعدادات وعدّل القيم (البريد وكلمة مرور المدير):

```bash
cp .env.example .env
```

```bash
npm start
```

ثم افتح:

| الصفحة | الرابط |
|---|---|
| موقع الوكالة | http://localhost:3000 |
| المتجر | http://localhost:3000/store |
| لوحة البائع/المدير | http://localhost:3000/seller |
| لوحة المشتري | http://localhost:3000/account |

### حساب المدير

يُنشأ تلقائياً عند أول تشغيل باستخدام `ADMIN_EMAIL` و `ADMIN_PASSWORD` من ملف `.env`.
إذا لم تحدد كلمة مرور، تُنشأ كلمة مرور عشوائية وتُحفظ في `data/admin-initial-password.txt`.
بعد الدخول غيّر كلمة المرور من «الملف الشخصي».

### المنتجات التجريبية

عند أول تشغيل تُضاف أقسام و30 منصة وحوالي 26 منتجاً **كأمثلة** (الأسعار بالدولار تقريبية). عدّلها أو احذفها من لوحة البائع ← المنتجات.
لإيقاف إضافتها في تثبيت جديد ضع `SEED_DEMO=false`.
لحذف كل البيانات والبدء من جديد:

```bash
npm run reset-db -- --yes
```

## مسار الطلب

1. المشتري يختار الاشتراك والباقة والكمية ← «اشترِ الآن» (يُطلب تسجيل الدخول).
2. يختار طريقة الدفع فتظهر تفاصيل الحساب (رقم الحساب/الآيبان/رقم المحفظة واسم المستفيد) والمبلغ بعملة الطريقة مع أزرار نسخ.
3. يحوّل المبلغ ثم يدخل **اسم المحوِّل** و**رقم الحساب المحوَّل منه** ويرفع **صورة الإيصال** (صورة أو PDF حتى 8MB) ← يُنشأ الطلب بحالة «بانتظار مراجعة الدفع» ويصل إشعار للمدير/البائع.
4. المدير/البائع يراجع الإيصال: **تأكيد الدفع** أو **رفض** مع ذكر السبب (يستطيع المشتري إعادة رفع إيصال صحيح من صفحة الطلب).
5. المدير/البائع يسلّم **بيانات الاشتراك** (حقول مثل البريد وكلمة المرور أو كود/رابط التفعيل + تعليمات + تاريخ الانتهاء) ← تظهر للمشتري في صفحة طلبه مع إشعار فوري، ويمكن إبلاغه عبر واتساب بزر واحد.
6. المشتري يؤكد الاستلام ويقيّم المنتج (أو يكتمل الطلب تلقائياً بعد 3 أيام).

صور الإيصالات **خاصة**: لا يراها إلا صاحب الطلب والمدير وبائع المنتج.

### الصلاحيات

- **المدير** يدير كل شيء. **البائع** يدير منتجاته وطلباتها فقط، ولا يستطيع أبداً إدارة طلب اشتراه بنفسه.
- افتراضياً يستطيع البائع تأكيد الدفع أو رفضه لطلبات منتجاته. لأن المبالغ تصل إلى حسابات المتجر، يمكنك قصر ذلك على المدير من **إعدادات المتجر ← السماح للبائعين بتأكيد أو رفض الدفع**؛ عندها يؤكد المدير الدفع ويصل للبائع إشعار بأن الطلب جاهز للتسليم.
- إذا أنشأ شخص حساباً بالبريد ثم سجّل صاحب البريد الحقيقي الدخول عبر Google بنفس البريد، يُنقل الحساب لصاحب Google وتُمسح كلمة المرور ورقم الواتساب القديمان ويُطلب منه إدخال رقمه (حماية من انتحال البريد). لا يُرقّى أي حساب إلى مدير تلقائياً عند التشغيل.

## تعديل محتوى الصفحة الرئيسية

- المنتجات والعروض والأسعار وطرق الدفع في الصفحة الرئيسية تُقرأ مباشرة من المتجر، فأي تعديل من لوحة البائع يظهر فوراً. يظهر «عرض لفترة محدودة» تلقائياً لأكبر خصم فيه عدّاد انتهاء.
- خدمات الوكالة وأرقامها («+150 مشروع منجز»…) ونقاط «لماذا MTS» وقائمة العملاء موجودة في `src/lib/content.js`، وشعارات العملاء في `public/img/clients/` (صور WebP مربّعة).
- قسم آراء المشترين يظهر تلقائياً بعد وجود 3 تقييمات حقيقية على الأقل.

## طرق الدفع والعملات

- طرق الدفع الأربع مضافة مسبقاً ويمكن تعديل كل تفاصيلها (الأرقام، الأسماء، التعليمات، العملة، الشعار) من **لوحة البائع ← طرق الدفع**.
- الأسعار محفوظة بالعملة الأساسية (الدولار افتراضياً)، وتُحوَّل للشيكل والجنيه حسب **أسعار الصرف** التي تحددها من **لوحة البائع ← العملات** (القيم المبدئية: 1$ = 3.10₪ و 53 ج.م — حدّثها حسب السوق). يُقرَّب المبلغ المطلوب للأعلى ويُحفظ مع الطلب، فلا يتأثر الطلب القديم بتغيير السعر لاحقاً.
- يمكن تغيير العملة الأساسية (مثلاً إلى الشيكل) وسيتم تحويل جميع أسعار المنتجات تلقائياً.

## تفعيل تسجيل الدخول عبر Google

1. ادخل إلى [Google Cloud Console ← Credentials](https://console.cloud.google.com/apis/credentials) وأنشئ مشروعاً.
2. اضبط **OAuth consent screen** (اسم التطبيق والبريد).
3. أنشئ **OAuth client ID** من نوع **Web application**.
4. في **Authorized JavaScript origins** أضف `http://localhost:3000` و `http://localhost` ورابط موقعك (مثل `https://store.example.com`).
5. انسخ الـ Client ID وضعه في `.env` بالمتغير `GOOGLE_CLIENT_ID` أو من **لوحة البائع ← إعدادات المتجر**.

يتم التحقق من رمز Google على الخادم، وإذا سجّل شخص عبر Google لأول مرة يُطلب منه إدخال رقم الواتساب قبل استخدام المتجر.

## النشر على الإنترنت

المتجر يحتاج خادم Node.js (لن يعمل على GitHub Pages لأنها تستضيف ملفات ثابتة فقط).

> **ملاحظة Vercel:** الملف `vercel.json` يجعل Vercel ينشر صفحة الوكالة الثابتة القديمة فقط (`index.html` و `assets/`) كما كانت، لأن Vercel لا يحفظ قاعدة البيانات والإيصالات بين التشغيلات. بعد تشغيل المتجر على استضافة Node وربط الدومين بها، يمكن حذف `vercel.json` أو إيقاف مشروع Vercel.

**الخيار 1 — خادم VPS (موصى به):**

```bash
npm install --omit=dev
```

```bash
NODE_ENV=production pm2 start server.js --name mts-store --node-args="--disable-warning=ExperimentalWarning"
```

ثم اجعل Nginx يمرّر الطلبات إلى المنفذ 3000 مع شهادة SSL (Let's Encrypt)، واضبط في `.env`:
`NODE_ENV=production` و `TRUST_PROXY=1` و `APP_URL=https://your-domain.com`.

**الخيار 2 — Railway / Render:** أنشئ خدمة Node من المستودع بأمر التشغيل `npm start`، وأضف **قرصاً دائماً (Volume)** واجعل `DATA_DIR` و `UPLOAD_DIR` يشيران إليه حتى لا تُحذف قاعدة البيانات والإيصالات عند إعادة النشر.

**النسخ الاحتياطي:** انسخ مجلدي `data/` و `uploads/` دورياً — فيهما كل البيانات والإيصالات.

## هيكل المشروع

```
index.html, assets/        صفحة الوكالة الثابتة القديمة (ينشرها Vercel عبر vercel.json؛ خادم Node يحوّل /index.html إلى الصفحة الرئيسية الجديدة)
server.js                  نقطة التشغيل
src/
  app.js, middleware.js    إعداد Express والأمان (CSP، حماية CSRF، الصلاحيات)
  db.js, seed.js           قاعدة البيانات والبيانات المبدئية
  lib/                     الطلبات، الكتالوج، العملات، الهاتف، الرفع، الإشعارات…
  routes/                  المتجر، الدخول، المشتري، البائع، المدير، API، الإيصالات
views/                     قوالب EJS (home = الصفحة الرئيسية، store, auth, account, seller, partials)
public/                    CSS و JavaScript والصور (شعارات المنصات)
test/e2e.test.js           الاختبار الشامل
```
